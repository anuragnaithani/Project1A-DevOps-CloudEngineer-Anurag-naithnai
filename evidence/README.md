# NovaPay Evidence Folder

This folder contains proof of implementation for the NovaPay zero-downtime DevSecOps pipeline.

## Evidence Categories

- pipeline/: GitHub Actions CI/CD pipeline screenshots
- monitoring/: Prometheus and Grafana monitoring screenshots
- scan-reports/: SonarQube, Trivy, OWASP ZAP and SBOM reports
- screenshots/: Kubernetes, Docker, LoadBalancer and application screenshots

## Required Evidence

- 8-stage CI/CD pipeline run
- Docker image build proof
- Kubernetes pods and services
- Blue-green deployment proof
- Canary deployment proof
- Trivy scan report
- SonarQube SAST report
- OWASP ZAP DAST report
- Grafana dashboard
